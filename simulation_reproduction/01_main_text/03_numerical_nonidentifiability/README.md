# Figure 5.1: numerical nonidentifiability

This directory contains the Euclidean manuscript's numerical-
nonidentifiability experiment for Section 5.1 and Appendix F.

`code/quantile_corrugated_density_curve_grid.R` is the base-R generator supplied
with the latest manuscript project. It constructs the planar, quantile-
calibrated corrugated alternatives and writes the exact four-by-five manuscript
panel to this directory.

Canonical asset: `figure_5_1_numerical_nonidentifiability.png`.
